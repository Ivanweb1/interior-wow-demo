# ОБЪЁМ — бетон → интерьер

Одноэкранная интерактивная промо-сцена интерьерной студии: ползунок синхронно меняет комнату, этап ремонта, бюджет, материалы и предметные метки.

## Локальный запуск

```bash
node tools/serve.mjs
```

Открыть `http://127.0.0.1:4480`. Для автодемо: `?demo=1`, для фиксированного кадра: `?p=0.7`.

Когда будет готов ролик Kling, положить его в `video/1-empty-to-final.mp4` и запустить `bash tools/build-seq.sh`.
